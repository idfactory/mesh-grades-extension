# Успеваемость ребенка

Локальное расширение для Chrome и совместимых Chromium-браузеров. На странице текущих оценок МЭШ оно по нажатию собирает оценки детей, чьи дневники доступны в текущем аккаунте, показывает короткую сводку и копирует подробный запрос для любого ИИ-чата. Последний результат сохраняется локально и сразу показывается при следующем открытии расширения. Имена детей в коде не заданы. Интеграция через API-ключи не планируется. Расширение само никуда не отправляет оценки.

## Установка

### Chrome

1. Скачайте архив `mesh-grades-extension-X.Y.Z.zip` со страницы [Releases](https://github.com/idfactory/mesh-grades-extension/releases) и распакуйте его. В корне распакованной папки должен быть `manifest.json`.
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.

### Яндекс Браузер

Попробуйте загрузить распакованную папку через страницу расширений. Для установки локального пакета Яндекс Браузер также описывает формат CRX3: его нужно перетащить на страницу `browser://tune`. Яндекс Браузер может отключать расширения из непроверенных источников после перезапуска, поэтому локальную установку может понадобиться включать снова. [Инструкция Яндекс Браузера](https://yandex.ru/support/browser/ru/personalization/extension).

## Использование

1. При первом запуске войдите в МЭШ и откройте **Оценки → Текущие оценки → По предмету**.
2. Нажмите на значок расширения. Оставьте его окно открытым до окончания первого сбора.
3. При следующих открытиях сразу появится последний сохранённый результат и время его сохранения — открывать МЭШ для просмотра не нужно. Чтобы получить свежие данные, откройте страницу оценок МЭШ и нажмите **Обновить результат**. Если обновление не удалось, предыдущий результат останется доступен.
4. В окне расширения показаны три предмета с самым низким средним баллом среди тех, где есть не менее трёх оценок. Это только краткий обзор: в запрос попадут все собранные предметы и оценки.
5. Нажмите **Скопировать запрос для ИИ**, затем выберите чат в разделе **Анализ с ИИ**: Алиса AI, DeepSeek, Qwen или ChatGPT. Вставьте текст в открывшийся чат. В запрос добавляется время сбора данных. Расширение заменяет имена детей в запросе по умолчанию; этот вариант можно изменить флажком. Перед отправкой проверьте комментарии учителей: в них могут быть другие личные сведения.

Если для нового сбора вкладка МЭШ не открыта, расширение прямо сообщит об этом. Сохранённый результат можно смотреть и копировать без МЭШ. Кнопка **Удалить сохранённые данные** очищает локальный снимок. Расширение не читает вкладки других сайтов и не передаёт оценки или учётные данные сторонним сервисам.

Ссылка **Напишите в репозитории** внизу окна открывает [GitHub Issues](https://github.com/idfactory/mesh-grades-extension/issues) для сообщений об ошибках и предложений. Она видна и без открытой вкладки МЭШ. Перед публикацией сообщения не прикладывайте снимки дневника с личными данными.

## Обновление локальной версии

Обновления локально установленного расширения **не устанавливаются автоматически**. Обновление понадобится только при исправлении ошибки или изменении интерфейса МЭШ.

**Chrome, распакованное расширение:** распакуйте новую версию, скопируйте её файлы в ту же папку, из которой расширение уже загружено, затем откройте `chrome://extensions` и нажмите кнопку перезагрузки на карточке расширения. После этого обновите вкладку МЭШ. Если выбрать новую папку через «Загрузить распакованное расширение», Chrome может показать вторую копию вместо обновления прежней. [Инструкция Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

**Яндекс Браузер, локальная установка:** установите обновлённый пакет вручную тем же способом, которым ставили предыдущий. Локальные сборки Яндекс Браузер может отключать после перезапуска. [Инструкция Яндекс Браузера](https://yandex.ru/support/browser/ru/personalization/extension).

## Как работает и что учитывать

- Читает текущий выбранный учебный период с видимой страницы МЭШ. Год около даты оценки МЭШ в карточке не показывает; расширение его не угадывает.
- Использует разметку веб-интерфейса МЭШ. После её обновления сбор может потребовать правки.
- Сохраняется один последний снимок в локальном хранилище расширения (`chrome.storage.local`), без истории предыдущих снимков. Он остаётся после закрытия браузера, пока вы не удалите его кнопкой в расширении или само расширение. Это локальные данные профиля браузера, поэтому на общем компьютере другие пользователи того же профиля могут открыть сводку.
- На странице МЭШ сбор переключает дневники и открывает карточки предметов; в конце возвращает исходный дневник.
- Ссылки в разделе **Анализ с ИИ** только открывают сайты чатов в новых вкладках. Запрос вставляется и отправляется вручную. API-ключи и автоматическая отправка оценок не используются.

Если подробности отдельной оценки не прочитались, запрос всё равно содержит саму оценку и пометку об ограничении сбора.

## Сборка и публикация версии

Версия тега должна совпадать с `manifest.json`: для версии `1.2.1` используйте тег `v1.2.1`. После отправки тега GitHub Actions запускает тесты, собирает ZIP с файлами расширения и прикрепляет его к GitHub Release. Архив с исходным кодом, который GitHub добавляет автоматически, для установки расширения не нужен.

Перед отправкой тега проверьте сборку локально:

```sh
npm test
python3 scripts/package_extension.py v1.2.1
```

После коммита версии в `main` отправьте тег `v1.2.1` в GitHub. Для следующих версий сначала обновите `manifest.json`, затем создайте тег с тем же номером.
